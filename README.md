# ちいさな鉄道

レールをパズルのようにつなぎ、3Dの列車を走らせる小さなブラウザゲームです。直線と左右のカーブを使って、ぐるっと一周するコースを作れます。列車はミント号とあかい特急の2種類から選べます。

## ブラウザであそぶ

[ちいさな鉄道をあそぶ](https://himico-yama.github.io/little-railway/)

リンクを開くだけで遊べます。コースの保存内容は、それぞれのブラウザに保存されます。

## はじめかた

1. Macでは「ゲームをはじめる.command」をダブルクリックします。Python 3と、WebGL対応のブラウザ（Chrome、Safariなど）が必要です。
2. ブラウザでゲームが開きます。開かない場合は、表示された `http://127.0.0.1:8765/` などのURLを開いてください。
3. 遊び終えたら、起動したターミナルで `Control + C` を押します。

ターミナルから起動する場合は、このフォルダで `python3 launcher.py` を実行します。インターネット接続や追加のパッケージは必要ありません。

## あそびかた

- 最初は完成した周回コースとミント号が用意されています。「しゅっぱつ！」を押すと走り、「ストップ」で止まります。
- コースを組みかえるには「レールをけす」を選び、外したいレールをクリックします。レールの種類を選び、空いた先の「＋」を押すと新しいレールをつなげられます。重なったり、向きが合わなかったりする場所には置けません。
- 「あたらしく」を押すと、まっすぐなレール1本から作り始められます。操作は「もどす」で取り消せます。
- 車両を選び、置きたいレールをクリックすると車両を設置できます。車両は1編成で、別の車両を置くと入れ替わります。
- 列車はつながっていない端で止まります。向きをかえるボタンで折り返せます。
- 画面をドラッグすると視点を回せます。スクロールやピンチでズームできます。
- コースと列車は使用中のブラウザに自動保存されます。ブラウザのデータを消去すると保存内容も消えます。
